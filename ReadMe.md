## 二、功能

- **課題練習**：點課題 → 順序練習／隨機練習／計時模擬（每題 45 秒）
- **錯題本**：只練曾答錯的題目，可按課題重做
- **統計**：各課題的已練次數與正確率
- **加題庫**：貼 JSON 或匯入 JSON 檔案

答題記錄存在瀏覽器 localStorage；題庫在檔案裡，走到哪都能用。

## 三、後期加題（三條通道）

### 通道 1：改 `extra-questions.js`（推薦）
與 `index.html` 同目錄，記事本或 VS Code 開啟，照現有格式複製貼上，存檔刷新即生效。檔案內含兩道範例題與課題代號對照表。

欄位說明：
```
id          唯一編號，如 "A-yueyang-x1"
section     "A"（甲部）
group       課題代號，見下方對照；不存在的代號會自動新建課題
groupTitle  顯示名稱
tag         題型標籤
stem        題幹
passage     （可選）篇章原文，顯示於題目上方
options     四個選項陣列
answer      正確選項序號，0=A、1=B、2=C、3=D
explain     解析
src         來源，如 "2022 DSE 卷一 甲部 Q3" 或 "模擬題"
```

### 通道 2：網頁內「加題庫」頁
選取 `.json` 檔案或直接貼 JSON → 按「匯入並合併」，存進 localStorage。

### 通道 3：直接改 `index.html` 的 `BANK`
搜尋 `var BANK = {` 即可找到題庫本體。
